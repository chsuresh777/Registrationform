# Registration Form 💻

A simple and responsive **Registration Form** built using **HTML, CSS, and JavaScript**.  
This project demonstrates client-side form validation, error handling, and data storage using browser **Local Storage**.

---

## 🚀 Features
- Responsive design using HTML & CSS 🎨  
- JavaScript validation for form inputs ✅  
- Real-time error messages for incorrect fields ⚠️  
- LocalStorage integration for saving user data 💾  
- Success message on valid registration 🎉

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
